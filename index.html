LANDING PAGE

Chess Dashboard

Optimus Tech

Uma Landing Page responsiva desenvolvida para simular a vitrine de uma plataforma de cursos focada em habilidades digitais (Web Design, Data Science, UI/UX e Cloud Security). O objetivo deste projeto foi aplicar conceitos modernos de desenvolvimento front-end, focando na construção de uma interface limpa, estruturação semântica e usabilidade.

Cool to do List

O CoolToDo foi desenvolvido para simplificar a organização diária através de uma interface prática e dinâmica.
A aplicação tem conceitos modernos, garantindo que a interação com as tarefas ocorra sem atritos. A interface foi construída para oferecer a mesma qualidade visual e de navegação tanto em dispositivos móveis quanto em desktops com um layout limpo e intuitivo para as ações do usuário.

SITE PORTIFOLIO

Galeria digital imersiva projetada para exibir trabalhos de design e arte digital de forma limpa e direta. O projeto atua como uma vitrine profissional para um artista freelancer, evidenciando o aspecto visual das obras

FILUM FATI

Uma aplicação web interativa que simula um oráculo de tarot focado na leitura de três cartas (passado, presente e futuro). A lógica da aplicação utiliza estruturas de arrays para gerenciar o baralho completo, controlando o sorteio dinâmico das cartas e exibindo suas respectivas interpretações dentro de um layout místico e imersivo.

CARD DE PERFIL

Publicado originalmente como conceito visual, este projeto ilustra a capacidade de organizar dados em um espaço reduzido, equilibrando hierarquia de informações e identidade visual. Ele serve perfeitamente como um elemento modular pronto para integrar aplicações web ou mobile mais complexas, atuando como um cartão de visita digital interativo.

Eu Sou o Rodrigo.

Na infância, descobri que desenhar era a melhor forma de dar vida ao que eu imaginava, hoje em dia descobrir onde posso fazer exatamente o que fazia quando criança, o desenvolvimento web, criando sites, ícones e ilustrações seja criando ferramentas do dia a dia ou desenvolvendo experiências temáticas e imersivas.

Meu foco é entregar experiências digitais únicas, visualmente incríveis, funcionais e totalmente acessíveis. Criar projetos incríveis é o que me move.

Por trás do codigo

Sou um desenvolvedor web e designer apaixonado por construir experiências digitais que realmente cativem quem as utiliza.

Como uma mente criativa, busco referências nas culturas, artes e em pessoas que fazem a diferença.

Trago uma visão focada em estruturar fluxos lógicos e eficientes para garantir que cada interface de App ou layout não seja apenas visualmente atraente, mas acima de tudo, única e funcional.
